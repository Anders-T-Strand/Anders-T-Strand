## Featured Projects

### [mas_deliberation_room](https://github.com/Anders-T-Strand/mas_deliberation_room)
A multi-agent system built with CrewAI where LLM agents deliberate to generate marketing strategies — each agent argues a position and the group converges on a recommendation.

### [sentiment_analysis](https://github.com/Anders-T-Strand/sentiment_analysis)
A replication and extension of Sun et al.'s *How to Fine-Tune BERT for Text Classification?* — a controlled experiment swapping BERT's `[CLS]` pooling for learned attention pooling on SST-2, which cut test error from 10.3% to 8.7%. Built for LING 5412.

### [multi_table_ml_prediction](https://github.com/Anders-T-Strand/multi_table_ml_prediction)
Integrates three separate datasets via engineered join keys, then compares Random Forest, XGBoost, and CatBoost on a binary classification task — XGBoost won at ~86% F1. Emphasis on leakage prevention and a reproducible preprocessing pipeline.

### [Masters_2026_Prediction](https://github.com/Anders-T-Strand/Masters_2026_Prediction)
A multi-script XGBoost pipeline that ranks the 2026 Masters field from free public data, blending the model's top-10 probability with market-implied odds and an Augusta-fit score. No paid APIs.

### [manhattan_apartment_rental_price](https://github.com/Anders-T-Strand/manhattan_apartment_rental_price)
A regression project predicting Manhattan apartment rents from listing features, built end to end in a notebook.
